# 앞으로

## 만들 것

- **다른 유틸에서 넘겨주기** — 경험치 측정기 · 사냥 타이머에 "성장 기록에 남기기" 버튼.
  받는 쪽은 이미 있다: `/log/?level=72&exp=1301770&inv=125000000&storage=300000000` 로 열면 폼을
  채우기만 하고 저장은 사용자가 한다. 남의 저장 키에 직접 쓰지 않는다.
- **태그** — 기록에 "경쿠", "사냥터 이동" 같은 태그를 달고 그래프 · 표를 거른다. 지금은 메모로 대신한다.
- **기록 달력** — 날짜별 경험치를 잔디처럼 보는 히트맵.
- **캐릭터 비교** — 본캐 · 부캐 성장 곡선을 레벨 기준으로 겹쳐 "같은 레벨대에서 누가 빨랐나".
- **공유 카드** — 기간 요약을 PNG 로 내보내기 (측정기의 결과 이미지 복사처럼).
- **경험치 vs 메소** — 사냥터를 옮겼을 때의 트레이드오프. 태그가 쌓여야 의미가 있다.

## 하지 않기로 한 것

- **하루의 시작 시각 설정** — 자정 고정. 새벽 사냥을 전날로 묶고 싶은 사람이 있겠지만 단순함이 낫다.
- **계정 단위 총자산** — 창고는 게임에서 계정 공유지만 캐릭터별로 적는다. 인벤 · 창고 칸을 나눈 건
  사용자가 덧셈하지 않게 하려는 것뿐이다.
- **메소 외 자산(아이템 평가액)** — 장비를 사면 메소가 줄어 손해처럼 보이지만, 메모로 설명한다.
- **사망 추정** — 같은 레벨에서 경험치가 줄어든 기록을 사망으로 세던 기능. 인게임에서 드문 일이라
  자리만 차지해서 뺐다. 그런 입력은 대개 오타라 저장 전에 확인만 받는다.
- **기기 간 동기화** — 서버가 없다. 기기를 옮길 때는 JSON 백업 → 불러오기.
